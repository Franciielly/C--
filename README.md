# Melhorias implementadas na linguagem C--

Foram realizadas melhorias na linguagem de programação C--, desenvolvida em Python, com o objetivo de ampliar suas funcionalidades e tornar a execução dos programas mais dinâmica e interativa.

Inicialmente, foram adicionados novos operadores matemáticos e relacionais, como o operador de módulo (`%`), utilizado para obter o resto de uma divisão, e os operadores `<=` e `>=`, que permitem realizar comparações de menor ou igual e maior ou igual. Também foi implementado o suporte a comentários utilizando o símbolo `#`, permitindo que o programador adicione observações ao código sem interferir em sua execução.

A principal melhoria foi a implementação da entrada de dados pelo usuário, tornando possível criar programas que não dependem apenas de valores definidos previamente no código. Para isso, foram adicionados dois novos comandos:

- **`ler()`**: permite receber informações em formato de texto digitadas pelo usuário durante a execução.
- **`ler_numero()`**: permite receber valores numéricos, incluindo números inteiros e decimais.

Com essas funcionalidades, a linguagem passou a permitir a criação de programas mais interativos, como calculadoras, sistemas de cadastro e aplicações que recebem informações e utilizam esses dados em operações e resultados.

Além disso, foram aprimorados os tratamentos de erros, incluindo situações em que o usuário informa um valor inválido ou utiliza operadores com tipos de dados incompatíveis. Também foram adicionados testes automatizados para verificar o funcionamento das novas funcionalidades e atualizada a documentação do projeto.

Dessa forma, as alterações ampliaram as possibilidades de utilização da linguagem C--, tornando-a mais funcional e oferecendo ao usuário maior liberdade para desenvolver programas interativos.
